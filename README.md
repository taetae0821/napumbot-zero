# 융통성 제로 AI 납품봇

학교·도서관·민원실의 엉뚱한 납품 사고를 고치며 배우는 공공조달 코미디 게임입니다.

## 실행

`index.html`을 Chrome 또는 Edge에서 열면 됩니다. 설치·서버·인터넷 연결이 필요 없습니다. 이 HTML 하나에 코드, 그림, 효과음이 모두 들어 있습니다.

- 3개 의뢰, 15개 항목, 45개 선택지
- 직접 그린 SVG 배경·캐릭터·사고 장면
- 선택 → 발주 → 결과 → 수정 → 최고 기록
- 소리, 큰 글자, 동작 줄이기, 키보드 조작
- 1080×1350 결과 카드 PNG 저장
- 진행은 현재 탭에만 저장됩니다. 새로고침하면 초기화됩니다.

## 플레이 화면 녹화

브라우저에서 게임을 열고 F11로 전체 화면을 켠 뒤, 화면 녹화를 시작하고 **게임 시작**을 눌러 직접 플레이합니다. 제출용 영상은 선택, 납품 결과, 조건 수정 장면이 보이도록 약 1분으로 편집하고 MP4·1080p 이상으로 저장합니다.

## 개발

사용자는 `index.html`만 있으면 됩니다. 아래 파일은 수정·검증용입니다.

- `src/data.js`: 의뢰·선택지·점수 규칙
- `src/art.js`: 오리지널 SVG 그림
- `src/style.css`: 반응형 화면과 애니메이션
- `src/game.js`: 상태·화면·결과 카드
- `tools/build.cjs`: 단일 HTML 빌드
- `tools/test.cjs`: jsdom 기반 흐름 검증
- `tools/art-preview.cjs`: 선택 장면을 PNG 모음으로 렌더링

Node.js가 있다면:

```sh
node tools/build.cjs
```

자동 테스트만 jsdom 26.1.0이 필요합니다. `npm install --no-save --ignore-scripts jsdom@26.1.0` 후 `node tools/test.cjs`를 실행합니다. 다른 폴더에 설치했다면 `NAPUM_TEST_MODULES` 환경변수로 그 `node_modules` 경로를 지정할 수 있습니다. 그림 미리보기는 sharp가 필요합니다.

## 검증 범위

729개 점수 조합, 전체 3라운드 버튼 흐름, 수정·재도전·최고 기록, 중복 타이머 방지, 45개 카드의 결과 화면, SVG 문법과 대표 그림 배치를 확인했습니다.

jsdom은 실제 브라우저 레이아웃을 그리지 않습니다. 이 환경의 로컬 HTML 브라우저 접근 제한으로 최종 브라우저 화면, 실기기 터치, 실제 PNG 다운로드·전체 화면·녹화 출력은 별도 확인이 필요합니다. Canvas 테스트는 텍스트·그리기 호출을 검사하며 실제 글꼴 렌더링을 보증하지 않습니다.

## 출품 전

공식 접수 서식·정확한 마감 시각·제출 파일명과 용량 조건은 주최 측 원문으로 확인해야 합니다. 제공된 기획서와 현재 게임은 실제 계약 절차 전체를 재현하지 않는 가상 교육 콘텐츠입니다. AI 활용 내역은 실제로 사용한 도구와 수정 범위에 맞게 작성하세요.
